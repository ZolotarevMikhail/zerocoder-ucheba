# Домашнее задание VPc04 — SQL, DBeaver, SQLite

Учебная база данных магазина спортивных товаров. Делал по уроку: сначала создал две таблицы прямо в DBeaver, потом наполнил их, поизменял, поудалял и в конце связал заказы с товарами через JOIN.

## Что здесь лежит

- `sql/queries.sql` — все запросы домашнего задания в одном файле, в том же порядке, что и на уроке. Каждый блок подписан коротким комментарием.
- `sql/шаг-*.sql` — те же запросы, но по частям, как я выполнял их в DBeaver (каждый шаг — отдельный скрипт).
- `screenshots/` — снимки из DBeaver: структура таблиц, данные, поиск через LIKE, JOIN.
- `code/seed.py` — скрипт, который засеял базу: 120 товаров и 48 заказов (по заданию товаров должно быть не меньше сотни, руками столько не вбить).
- `code/безопасность-демо.py` — демонстрация SQL-инъекции: как НЕ надо собирать запрос (конкатенацией) и как надо (через `?`).

## Структура базы

Таблица `products`: название, описание, категория, цена, артикул (уникальный).
Таблица `orders`: товар, количество, дата; связывается с товаром по `product_id`.

## Как воспроизвести

1. Создать в DBeaver соединение SQLite на файл `learning.db` (или любой другой файл — путь задаётся при создании соединения).
2. Выполнить `sql/шаг-2-таблицы.sql` — создастся две таблицы.
3. Запустить `python3 code/seed.py` — наполнит таблицы (120 товаров + 48 заказов).
4. Дальше по файлам: `шаг-3-insert.sql` (ручные вставки), `шаг-4-update.sql`, `шаг-5-delete.sql`, `шаг-6-чтение.sql`, `шаг-7-join.sql`.
5. Числа для самопроверки: после seed — 120 товаров; после ручных вставок — 126; после DELETE тестовых — 123. Заказов 48, все они связаны с товарами (сирот в таблице нет).
